What is llms.txt? Does it help you show up in ChatGPT and Gemini?

Phan Minh Hoàng

SEO and GEO specialist, SEO Leader at Forza

Published 13/11/2026. 3 min read.

llms.txt is a Markdown text file served at a website's /llms.txt address that summarises what the site is and lists its most important pages for large language models (LLMs) to read. It's a proposal, not a standard: Google says Google Search doesn't use it, and log data shows very few AI bots ever fetch it.

1. What is llms.txt?

llms.txt was proposed by Jeremy Howard (Answer.AI) on 3 September 2024 as a way for websites to introduce themselves briefly to AI models. Instead of leaving AI to parse full HTML pages with menus, ads and JavaScript, a site places a short Markdown file at its root: what the site is about, which pages matter and where they are.

The original target was software documentation: AI coding tools need to read API docs quickly and cleanly. Many business websites later added the file hoping AI would mention them more often.

3. The structure of an llms.txt file

Per the specification on llmstxt.org, the file contains, in order:

  • An H1 with the site or project name. This is the only required part.
  • A blockquote summarising the site in a few sentences.
  • Optional extra detail, without headings.
  • H2 sections, each a list of links in the form [name](url): notes.
  • An "Optional" section: secondary links an AI can skip when it needs less context.

A short example:

# Business name

> Short description: what the business does, where, for whom.

## Services
- [Service A](https://example.com/service-a/): one-line description

## Optional
- [Blog](https://example.com/blog/)

The spec also suggests offering a Markdown version of important pages at the same URL with .md appended. You can see this site's own file at /llms.txt.

4. What does Google say about llms.txt?

  • Google's official documentation (Google's Guide to Optimizing for Generative AI Features, updated 10 July 2026) says Google Search doesn't use llms.txt files, and creating one will neither harm nor help visibility or rankings in Google Search.
  • Gary Illyes (Google) said at a Search Central Deep Dive event in 2025 that Google doesn't support llms.txt and isn't planning to.
  • John Mueller (Google) compared llms.txt to the old keywords meta tag: sites declare whatever they like, which invites abuse.

In other words, llms.txt has no effect on Google AI Overviews and AI Mode. Both run on the same systems as Google Search, as explained in what are AI Overviews and AI Mode.

These figures are compiled in Optimizely's analysis (October 2026). The common thread: no major AI platform has confirmed using llms.txt when choosing sources. The few requests that do happen come mostly from AI coding tools, which matches the proposal's original purpose.

Frequently asked questions

What is llms.txt?

llms.txt is a Markdown file served at a site's /llms.txt address that summarises the site and lists its key pages for AI models. Jeremy Howard (Answer.AI) proposed it in September 2024.

Does Google use llms.txt?

No. Google's documentation states Google Search doesn't use llms.txt, and creating one doesn't affect rankings or visibility in Google Search, including AI Overviews and AI Mode.

Can llms.txt replace robots.txt?

No. robots.txt controls which bots may crawl which pages. llms.txt is only a content summary; it doesn't allow or block anything.

Should a business website have llms.txt?

It's optional. The file is harmless and cheap, but there's no evidence it gets a site mentioned more by AI. It's clearly useful for software documentation sites.
